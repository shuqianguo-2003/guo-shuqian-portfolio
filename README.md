# Guo Shuqian — Personal Portfolio

A bilingual personal portfolio for marketing, brand communication and content operations work. The site presents education, experience and selected market-entry and communication projects in Chinese and English.

## Live site

[guo-shuqian-marketing.sguo0060.chatgpt.site](https://guo-shuqian-marketing.sguo0060.chatgpt.site)

## Highlights

- Chinese and English interface
- Education and professional experience timeline
- Downloadable resume
- Selected brand strategy and market-entry projects
- Responsive portfolio layout

## Tech stack

- React 19
- TypeScript
- Vinext and Vite
- Tailwind CSS
- shadcn/ui components
- Cloudflare Workers-compatible build

## Run locally

Requirements: Node.js 22.13 or newer and pnpm.

```bash
pnpm install
pnpm dev
```

Then open the local URL shown in the terminal.

## Build

```bash
pnpm build
```

## Note

This repository contains the original editable project source used for the published portfolio, not a downloaded copy of the rendered website.
